# Municipal Report Management System

C89/C99 project developed for the Computer Science course at the University of Salerno.

## Project Description

This application allows a municipality to manage citizen reports related to urban issues such as:

- road damage
- broken street lights
- abandoned waste
- public infrastructure failures

The system supports:

- report registration
- report search
- status updates
- urgency management
- filtered visualization
- statistical report generation

## Technologies

- C89/C99
- Abstract Data Types (ADT)
- Linked Lists
- Modular Programming
- Makefile
